# Source assets — drop originals here

originals; the build pipeline writes optimised output into `public/`.

  3d/           Blender scenes (.blend), exported frame renders
  photography/  RAW / full-res originals from the factory + project shoots
  brand/        logo vector (.ai/.svg), any existing brand guidelines
  video/        camera originals, drone footage
  documents/    datasheets, certifications, spec PDFs, company profile
